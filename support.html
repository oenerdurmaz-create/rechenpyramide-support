Über die App

Rechenpyramide ist ein spielerisches Mathe-Lernspiel für Kinder. Es bietet Rechenpyramiden, mehrere Schwierigkeitsstufen, Sterne, Level, Tagesziele und eine optionale Zeit-Challenge.

Bei Problemen

Bitte sende uns nach Möglichkeit folgende Angaben:

  • iPhone- oder iPad-Modell
  • iOS-/iPadOS-Version
  • Sprache der App
  • kurze Beschreibung des Problems
  • optional einen Screenshot

Datenschutz

Rechenpyramide sammelt keine personenbezogenen Daten, verwendet keine Werbung und kein Tracking. Spielstände werden lokal auf dem Gerät gespeichert.

About the app

Rechenpyramide is a playful math-learning game for children with number pyramids, multiple difficulty levels, stars, unlockable levels, daily goals, and an optional Time Challenge.

If you need help

Please include, if possible:

  • iPhone or iPad model
  • iOS/iPadOS version
  • app language
  • a short description of the issue
  • optionally, a screenshot

Privacy

Rechenpyramide does not collect personal data, use advertising, or perform tracking. Game progress is stored locally on the device.
